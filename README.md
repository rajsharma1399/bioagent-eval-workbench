# BioAgent Eval Workbench 🧬

A simple, interactive web tool designed to test and benchmark AI agents on computational life science tasks like genomics, structural biology, and drug discovery.

## What It Does
This project simulates an automated evaluation environment where you can:
* Select different scientific pipelines (Genomics, Structural Biology, Transcriptomics, and Drug Discovery).
* Test how AI agents generate Python scripts using libraries like **Biopython**.
* Run live simulations to check code execution, syntax validation, and deterministic scientific assertions.

## Features
* **Interactive Terminal Simulator:** See how agent-driven workflows execute step-by-step in a virtual Python/Docker environment.
* **Ground Truth Validation:** View automated checks and scoring rubrics for biological calculations.
* **Zero Setup Required:** Built purely with HTML, Tailwind CSS, and JavaScript—runs instantly in any web browser.

## How to Use
1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Choose a domain pipeline, select an AI model target, and click **Execute Agent Evaluation**.
